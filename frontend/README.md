# CivicFlow Frontend

React 18 + Vite + Tailwind CSS frontend for CivicFlow.

## Running in Development

```bash
# Install dependencies
npm install

# Start development server
npm run dev
```

Server starts at `http://localhost:5173`.
Communicates with backend API at `http://localhost:8000` (configured via `VITE_API_URL` in `.env`).
